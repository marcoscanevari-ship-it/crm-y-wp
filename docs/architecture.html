ZOKKIA CRM — Arquitectura del sistema (WhatsApp + IA)

Next.js 16 en Vercel · Supabase (Postgres + Auth) · WhatsApp Cloud API (Meta) · OpenRouter (GPT-5 Nano) · Resend

Flujo resumen: Contacto escribe por WhatsApp → Meta reenvía el mensaje al webhook (Vercel) → el webhook guarda todo en Supabase, le pide una respuesta al modelo IA (OpenRouter · gpt-5-nano) y la envía de vuelta por WhatsApp → si detecta un lead calificado, corre qualify.ts y (opcional) dispara un email por Resend. Los crons de Vercel corren en horarios fijos para seguimiento de leads fríos y el resumen diario. El admin entra al panel con magic link (Supabase Auth) y ve/gestiona todo con RLS.
